# Ashveil Console 设计笔记

这个项目的目标是做一个轻量、偏暗色、适合内部使用的管理控制台。当前阶段更像一个可运行的原型：前端负责界面和路由，后端提供一组模拟接口，后面可以逐步替换成真实业务数据。

## 模块划分

### auth

负责登录、JWT 签发和当前用户信息。

### access

负责身份权限相关数据，例如用户、角色、菜单等。现在用 mock 数据表达结构，后面可以接数据库。

### dictionary

维护系统里常见的枚举配置，例如账号状态、风险等级、来源渠道。

### audit

记录控制台里的关键动作，便于回溯谁在什么时间做了什么。

### scheduler

展示后台任务定义、运行状态和成功率，后续可以接入真实定时任务服务。

### monitor

展示 API 运行时间、CPU、内存、QPS 和节点状态。

## 前端页面

- `/login`：登录页
- `/dashboard`：星图总览
- `/access/users`：身份权限
- `/system/dictionaries`：数据字典
- `/audit/logs`：审计轨迹
- `/jobs`：任务编排
- `/monitor`：系统脉搏

## 设计风格

- 黑白灰为主
- 少量玻璃拟态卡片
- 大标题 + 小标签的信息层级
- 侧边栏固定，内容区以卡片和面板组织
