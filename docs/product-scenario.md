# Ashveil Console 业务设定

Ashveil Console 的业务设定是：**内部风险观察台 / 夜间值守控制台 / 权限审计中枢**。

它不是一个泛泛的后台管理系统，而是一个帮助维护者观察内部系统灰域状态的控制台。

## 1. 内部风险观察台

风险不只来自明显的报错，也来自权限、账号、任务、接口和节点状态之间的微小变化。

Ashveil Console 把以下信号放在一起观察：

- 账号状态；
- 角色授权；
- 审计日志；
- 异常动作；
- 任务执行状态；
- 节点健康状态。

## 2. 夜间值守控制台

夜间值守时，维护者不需要花哨界面，需要的是低噪声、高可读、能快速发现异常的界面。

因此 Ashveil Console 的页面结构更偏向：

- 暗色背景；
- 大标题；
- 清晰卡片；
- 状态标签；
- 时间线；
- 可筛选表格。

## 3. 权限审计中枢

权限是 Ashveil Console 的核心观察对象之一。项目中的角色权限矩阵不是装饰，而是为了表达：谁能访问什么资源、能执行哪些动作、是否存在过度授权。

后续权限模块会继续向以下方向演进：

- 授权变更记录；
- 权限快照对比；
- 高危动作标记；
- 角色风险评分；
- 权限变更审批流。

## 4. 与普通后台的区别

普通后台更强调“管理数据”。Ashveil Console 更强调“观察变化”。

| 普通后台 | Ashveil Console |
| --- | --- |
| 增删改查 | 观察、筛选、追踪、复盘 |
| 通用菜单 | 风险、权限、审计、任务、脉搏 |
| 明亮业务系统 | 暗色值守环境 |
| 功能堆叠 | 灰域状态显影 |

## 5. 一句话定位

Ashveil Console 是一个把权限、审计、任务与系统脉搏连接起来的灰域观察控制台。
