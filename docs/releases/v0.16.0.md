# v0.16.0 发布说明

本次版本新增灰域风险评分系统，让 Ashveil Console 从“展示风险信号”进一步升级为“计算风险信号”。

## 新增

- 新增 `backend/src/risk.js` 风险评分模型。
- 新增 `/api/risk/scores` 后端接口。
- 新增“灰域评分”菜单入口。
- 新增 `RiskScores` 前端页面。
- 支持对角色、用户、审计主体、任务、节点进行统一风险评分。
- 风险等级分为低风险、中等、偏高、高危。

## 评分模型

风险分由以下因素合成：

- 权限敏感度；
- 审计级别权重；
- 任务稳定性；
- 节点资源压力；
- 状态修正。

## 优化

- README 增加灰域评分说明。
- 版本号更新为 `v0.16.0`。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
