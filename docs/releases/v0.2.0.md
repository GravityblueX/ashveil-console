# v0.2.0 发布说明

这次版本主要围绕项目可读性、运行体验和中文文档做了一轮整理。

## 新增

- 新增根目录 `package.json`，提供统一命令：
  - `npm run install:all`
  - `npm run dev:backend`
  - `npm run dev:frontend`
  - `npm run build`
  - `npm run check`
- 新增 `backend/.env.example` 和 `frontend/.env.example`。
- 后端 `/api/health` 增加版本信息。
- 前端通用模块页增加加载状态和错误状态。

## 优化

- README 改为更完整的简体中文项目介绍。
- 补充功能模块表、技术栈、启动流程、目录结构和后续计划。
- 更新前后端 package 版本到 `0.2.0`。

## 验证

- 已执行前端构建检查：`npm run build`。
