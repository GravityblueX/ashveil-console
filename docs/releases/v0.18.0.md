# v0.18.0 发布说明

本次版本新增夜间值守模式，让 Ashveil Console 更贴近“夜间值守控制台”的产品设定。

## 新增

- 新增 `/api/watch/night` 后端接口。
- 新增“夜间值守”菜单入口。
- 新增 `NightWatch` 前端页面。
- 提供实时值守时钟。
- 提供平均风险、待确认事件、处理中事件、在线节点四类值守指标。
- 提供风险事件聚光区。
- 提供低噪声检查单。
- 支持“进入专注”全屏式观察模式。

## 优化

- README 增加夜间值守模式说明。
- 版本号更新为 `v0.18.0`。
- 进一步强化 Ashveil 的夜间值守与灰域观察产品定位。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
