# v0.22.0 发布说明

本次版本进入“新功能建议与实现”阶段，新增功能建议中心与路线图视图，用于沉淀 Ashveil Console 后续演进方向。

## 新增

- 新增 `backend/src/ideas.js` 功能建议数据与路线图生成模型。
- 新增 `/api/ideas` 后端接口。
- 新增“功能建议”菜单入口。
- 新增 `IdeasRoadmap` 前端页面。
- 路线图按“下一步 / 计划中 / 调研中”分组展示。
- 每条建议包含优先级、影响值、工作量、业务原因和摘要。

## 优化

- README 增加功能建议中心模块说明。
- 版本号更新为 `v0.22.0`。
- 为后续持续优化提供清晰候选池。

## 验证

- 已执行 `npm run format`、`npm run build` 与 `npm run check`。
