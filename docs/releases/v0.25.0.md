# v0.25.0 发布说明

本次版本继续推进 Prisma 运行时接入，把权限矩阵接口升级为 Prisma 优先读取，并保留 mock 数据兜底。

## 新增

- `getPermissionMatrix()` 仓储方法。
- `GET /api/access/permission-matrix` 支持 Prisma 数据源。
- 新增 `docs/permission-matrix-prisma.md`。
- 权限矩阵接口响应增加 `meta.source` 与 `meta.prisma`。

## 读取策略

- Prisma 可用且资源、角色数据存在时，读取 `PermissionResource`、`PermissionAction`、`Role`、`PermissionGrant`。
- Prisma 不可用或数据为空时，自动回退 `store.js` 的 mock 权限矩阵。
- 保持现有前端权限矩阵页面兼容。

## 优化

- README 增加权限矩阵 Prisma 迁移说明入口。
- 版本号更新为 `v0.25.0`。

## 验证

- 已执行 `npm run format`、`npm run build` 与 `npm run check`。
