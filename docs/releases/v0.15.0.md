# v0.15.0 发布说明

本次版本围绕“让 Ashveil Console 更像完全个人原创项目”进行强化，重点补充项目缘起、独有设计语言和业务设定。

## 新增

- 新增 `docs/origin-story.md`，解释 Ashveil 名称来源与“灰域控制台”概念。
- 新增 `docs/design-language.md`，沉淀 Ashveil 的色板、间距、组件命名和交互原则。
- 新增 `docs/product-scenario.md`，将项目业务设定明确为：内部风险观察台 / 夜间值守控制台 / 权限审计中枢。

## 优化

- README 重写为更具个人项目气质的简体中文介绍。
- 登录页文案从普通后台描述调整为“看见权限、审计、任务与系统脉搏之间的灰域变化”。
- 顶部命名从通用控制台进一步调整为“灰域观察台”。
- 版本号更新为 `v0.15.0`。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
