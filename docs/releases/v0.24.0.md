# v0.24.0 发布说明

本次版本开始把 SQLite + Prisma 数据层接入运行时，优先从 Prisma 读取用户和角色数据，并保留 mock 数据兜底。

## 新增

- 新增 `backend/src/db.js`。
- 新增 `backend/src/repositories.js`。
- 新增 `docs/prisma-runtime.md`。
- 登录接口支持 Prisma 优先读取。
- 当前用户接口支持 Prisma 优先读取。
- 用户列表与角色列表接口支持 Prisma 优先读取。
- 接口响应增加数据来源 meta 信息。

## 兼容策略

- Prisma Client 可用时读取 SQLite；
- 数据库未初始化或连接失败时自动回退 `store.js` mock 数据；
- 保证未执行迁移的环境仍可正常启动和演示。

## 优化

- README 增加 Prisma 运行时接入文档入口。
- 版本号更新为 `v0.24.0`。

## 验证

- 已执行 `npm run format`、`npm run build` 与 `npm run check`。
