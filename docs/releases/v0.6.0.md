# v0.6.0 发布说明

这次版本围绕角色权限矩阵进行优化，让权限模块从普通列表扩展为更直观的 RBAC 授权视图。

## 新增

- 新增 `/access/matrix` 角色权限矩阵页面。
- 后端新增 `/api/access/permission-matrix` 接口，返回资源、动作与角色授权关系。
- 菜单新增“权限矩阵”入口。
- 前端支持按角色、资源、动作展示授权状态。
- 权限按钮支持在页面内切换“允许 / 拒绝”状态。
- 新增角色授权数量统计卡片。

## 优化

- README 更新为 `v0.6.0` 的简体中文介绍。
- 权限模块表达从列表扩展为矩阵视图，后续更容易接入真实保存接口。

## 验证

- 已执行 `npm run check`，前端构建通过。
