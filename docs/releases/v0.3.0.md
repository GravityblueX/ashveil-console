# v0.3.0 发布说明

这次版本把模块页从原始 JSON 输出升级成了真正的暗色数据表格，让项目更接近可使用的后台控制台。

## 新增

- 新增 `DataTable` 通用表格组件。
- 增加表头、空状态、状态标签、列表字段展示和行操作按钮。
- 为用户、字典、审计日志、任务、监控等模块配置了中文列名。
- 监控模块支持把 API 指标和节点状态转换成表格数据。

## 优化

- 模块页不再直接展示 JSON，改为统一表格布局。
- 增强暗色表格样式，包括 hover、边框、状态色和操作按钮。
- README 更新为 `v0.3.0` 的简体中文介绍。

## 验证

- 已执行 `npm run check`，前端构建通过。
