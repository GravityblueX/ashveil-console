# v0.17.0 发布说明

本次版本新增风险事件中心，把灰域风险评分进一步转换成可处理、可跟进的事件队列。

## 新增

- 新增 `backend/src/risk-events.js` 风险事件生成模型。
- 新增 `/api/risk/events` 后端接口。
- 新增“风险事件”菜单入口。
- 新增 `RiskEvents` 前端页面。
- 风险事件支持状态：待确认、处理中、已确认、已忽略、已归档。
- 根据风险等级自动生成处理建议。

## 优化

- README 增加风险事件中心说明。
- 版本号更新为 `v0.17.0`。
- Ashveil 的产品闭环从“观察风险”推进到“跟进风险”。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
