# v0.5.0 发布说明

这次版本围绕弹窗表单进行优化，让模块页具备新增、查看和编辑的基础交互原型。

## 新增

- 新增 `FormModal` 通用弹窗表单组件。
- 模块页新增“新增”按钮。
- 表格行操作支持触发查看/编辑弹窗。
- 用户、字典、审计日志、任务等模块配置了对应表单字段。
- 表单保存后显示草稿反馈，便于后续接入真实接口。

## 优化

- `DataTable` 支持向外抛出行操作事件。
- 弹窗适配暗色主题、窄屏布局和 textarea 字段。
- README 更新为 `v0.5.0` 的简体中文介绍。

## 验证

- 已执行 `npm run check`，前端构建通过。
