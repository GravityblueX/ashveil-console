# v0.23.0 发布说明

本次版本进入 SQLite + Prisma 数据层设计阶段，为 Ashveil Console 从 mock 原型升级到可持久化系统做准备。

## 新增

- 新增 `backend/prisma/schema.prisma`。
- 新增 `backend/prisma/seed.js`。
- 后端新增 Prisma 相关脚本：
  - `db:generate`
  - `db:migrate`
  - `db:studio`
  - `db:seed`
- `backend/.env.example` 增加 `DATABASE_URL`。
- 新增 `docs/data-layer-plan.md` 数据层设计与迁移计划。

## 数据模型

本轮 schema 覆盖：

- 用户与角色；
- 用户角色关系；
- 权限资源、动作与授权；
- 审计日志；
- 风险事件；
- 任务；
- 权限快照。

## 优化

- README 增加 Prisma / SQLite 技术栈说明。
- README 增加数据层设计文档入口。
- 版本号更新为 `v0.23.0`。

## 验证

- 已执行 `npm run format`、`npm run build` 与 `npm run check`。
