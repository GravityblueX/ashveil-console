# v0.7.0 发布说明

这次版本围绕审计日志进行增强，让审计模块从普通明细表扩展为可观察风险态势的审计中心。

## 新增

- 新增 `/api/audit/summary` 审计摘要接口。
- 新增 `AuditCenter` 审计中心页面。
- 审计中心增加总日志、高危、警告、信息四类指标卡片。
- 增加渠道分布条形视图。
- 增加最近风险时间线。
- 审计明细继续复用表格、筛选和弹窗能力。

## 优化

- 审计日志 mock 数据增加更多风险场景。
- README 更新为 `v0.7.0` 的简体中文介绍。
- 审计模块从单一列表升级为摘要 + 时间线 + 明细的组合视图。

## 验证

- 已执行 `npm run check`，前端构建通过。
