本次版本围绕 Ashveil UI 组件库进行优化，开始把项目中反复出现的暗色界面元素沉淀为可复用组件和设计令牌。

- 新增 `frontend/src/styles/tokens.css` 设计令牌文件。
- 新增 `frontend/src/components/ash/AshButton.vue`。
- 新增 `frontend/src/components/ash/AshCard.vue`。
- 新增 `frontend/src/components/ash/AshBadge.vue`。
- 新增 `frontend/src/components/ash/AshMetricCard.vue`。
- 新增 `frontend/src/components/ash/index.js` 统一导出入口。
- 新增 `docs/ashveil-ui.md` 组件库说明文档。

## 优化

- README 增加 Ashveil UI 组件库入口说明。
- 版本号更新为 `v0.19.0`。
- 为后续页面统一视觉、减少重复样式和沉淀个人设计体系打基础。
