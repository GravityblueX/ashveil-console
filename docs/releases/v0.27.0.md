# v0.27.0 发布说明：风险事件处置轨迹

本次版本在风险事件状态持久化基础上继续补齐处置闭环，为 `RiskEvent` 增加处置备注、操作人和状态变更审计日志。

## 新增

- `RiskEvent.statusNote`：保存最近一次处置备注。
- `RiskEvent.handledBy`：保存最近一次操作人。
- `RiskEvent.statusChangedAt`：保存最近一次状态变更时间。
- `RiskEventStatusLog`：独立记录状态变更轨迹。
- `docs/risk-event-audit-trail.md` 设计说明。

## 接口优化

- `PATCH /api/risk/events/:eventKey/status` 支持提交 `note`。
- 后端从 JWT 中读取 `req.user.username` 作为操作人。
- 状态更新时同时写入当前处置字段和状态日志。
- `GET /api/risk/events` 返回每个事件最近 5 条状态轨迹。

## 前端优化

- 风险事件状态变更时提示输入处置备注。
- 风险事件卡片展示最近处置备注、操作人和变更时间。
- 新增“轨迹”按钮，查看最近状态变更记录。
- 保存失败时同时回滚状态与备注。

## 验证

- 已执行 `npm run format`。
- 已执行 `npm run build`。
- 已执行 `npm run check`。

## 风险提示

- 本版本新增 Prisma 字段和模型；已有数据库需要同步 schema 后再启用持久化写入。
- Prisma 不可用时，风险事件列表仍可运行时生成，但状态更新会返回 `503`。
