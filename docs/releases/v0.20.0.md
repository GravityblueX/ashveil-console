# v0.20.0 发布说明

本次版本进入性能优化阶段，重点降低前端首屏负载，并减少后端聚合计算接口的重复计算。

## 新增

- 新增 `backend/src/cache.js` 轻量内存缓存工具。
- 风险评分、风险事件、夜间值守聚合接口增加短 TTL 缓存。
- 聚合接口响应增加 `meta.cache`、`generatedAt`、`ttlMs` 等元信息。

## 优化

- 前端路由改为异步组件懒加载。
- Vite 构建增加手动分包策略：`vendor`、`risk-audit`、`watch`、`ash-ui`。
- 前端风险评分、风险事件、夜间值守页面兼容聚合接口的新响应结构。
- README 增加性能策略说明。
- 版本号更新为 `v0.20.0`。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
