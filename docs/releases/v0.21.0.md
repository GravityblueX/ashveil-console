# v0.21.0 发布说明

本次版本进入代码规范优化阶段，为 Ashveil Console 补充 ESLint 与 Prettier 基础规范配置。

## 新增

- 根目录新增 `.prettierrc`。
- 根目录新增 `.prettierignore`。
- 后端新增 `backend/eslint.config.js`。
- 前端新增 `frontend/eslint.config.js`。
- 根目录新增 `format` 与 `format:check` 脚本。
- 后端与前端补充 `lint` / `format` 脚本。

## 优化

- `npm run check` 现在包含 lint、格式检查和测试占位流程。
- README 增加代码规范说明。
- 版本号更新为 `v0.21.0`。

## 验证

- 已执行 `npm run format`、`npm run build` 与 `npm run check`。
