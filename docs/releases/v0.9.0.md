# v0.9.0 发布说明

本次版本对应自动化持续优化流程的第 2 步：创建 GitHub Actions 流水线。

## 新增

- 新增 `.github/workflows/continuous-optimize.yml`。
- 支持 push 到 `main` / `master` 自动触发。
- 支持每天 UTC 02:00 定时触发。
- 支持 `workflow_dispatch` 手动触发。
- 流水线包含依赖安装、构建检查、自动提交和 Release 创建步骤。

## 优化

- README 增加自动化流水线说明。
- 版本号更新为 `v0.9.0`。

## 验证

- 已执行 `npm run build` 与 `npm run check`。
