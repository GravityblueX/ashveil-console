# v0.26.0 发布说明：风险事件状态持久化到 Prisma

本次版本继续推进 Ashveil Console 的数据层迁移，将风险事件中心的状态流转接入 Prisma，让值守处置进度可以被保存和复用。

## 新增

- `RiskEvent.eventKey` 稳定事件键，用于关联评分生成事件与数据库记录。
- `getRiskEvents()` 仓储方法：自动生成风险事件并同步到 Prisma。
- `updateRiskEventStatus()` 仓储方法：持久化风险事件状态。
- `PATCH /api/risk/events/:eventKey/status` 状态更新接口。
- `docs/risk-event-status-prisma.md` 设计与运行说明。

## 优化

- `GET /api/risk/events` 改为 Prisma 优先读取，并返回 `meta.source` 与 `meta.prisma`。
- 风险事件前端状态下拉框由本地修改升级为后端保存。
- 状态保存失败时前端自动回滚，避免误判。
- 风险事件概览增加 `ignored` 统计。
- 风险事件使用稳定 `eventKey`，避免运行时序号变化导致状态错配。

## 回退策略

- Prisma 可用时：事件状态从 `RiskEvent` 表读取和更新。
- Prisma 不可用时：风险事件列表继续由运行时评分模型生成。
- Prisma 不可用时更新状态返回 `503`，明确提示无法持久化。
