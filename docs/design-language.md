# Ashveil Design Language

Ashveil Console 的设计语言围绕“灰域观察”展开。它不追求强烈品牌色，而是通过黑、白、灰、低饱和状态色和玻璃质感，营造一种冷静的内部控制台氛围。

## 设计关键词

- **灰域**：介于正常与异常之间的观察区。
- **低噪声**：避免大面积高饱和色，减少视觉疲劳。
- **夜间值守**：默认暗色环境，适合长时间监控。
- **可追溯**：强调时间线、日志、权限变化和状态痕迹。
- **克制反馈**：操作反馈清楚，但不夸张。

## 色板

| 名称       | 色值      | 用途               |
| ---------- | --------- | ------------------ |
| Obsidian   | `#09090b` | 主背景             |
| Charcoal   | `#111113` | 输入框、深层面板   |
| Graphite   | `#27272a` | 卡片、边框、分隔层 |
| Mist       | `#a1a1aa` | 次级文字           |
| Bone       | `#f4f4f5` | 主文字、主按钮     |
| Ember Red  | `#fca5a5` | 高危状态           |
| Amber Fog  | `#fcd34d` | 警告状态           |
| Pale Green | `#dcfce7` | 健康/成功状态      |

## 间距规则

- 页面主边距：`32px`
- 面板内边距：`24px`
- 卡片圆角：`18px - 26px`
- 表格单元格：`13px - 16px`
- 组件间距：`12px / 16px / 18px`

## 组件命名

Ashveil 的组件命名强调用途，而不是视觉形式：

- `DataTable`：灰域数据表格；
- `FilterBar`：观察筛选条；
- `FormModal`：字段化草稿弹窗；
- `PermissionMatrix`：角色授权矩阵；
- `AuditCenter`：审计观察中心。

## 交互原则

1. **先观察，再操作**：页面优先呈现态势与上下文，再提供编辑按钮。
2. **操作不打断观察**：弹窗覆盖但不跳转，减少上下文丢失。
3. **状态必须可见**：健康、警告、高危都使用标签或时间线标记。
4. **默认克制**：按钮、标签、提示都保持低饱和，只有风险状态使用轻微强调。
5. **保留痕迹**：每个模块都应逐渐补充日志、时间线或变更摘要。
