# Ashveil Console

Ashveil Console 是一个暗色系、轻量化的内部管理控制台。它更像是我突然想做一个“夜间值班台”时顺手搭出来的小项目：把登录、权限、字典、审计、任务和监控这些后台常见能力先串起来，保持结构清楚、页面简洁，后面想接真实业务时也比较容易继续扩展。

界面整体采用黑白灰与低饱和配色，减少高亮色，强调信息密度和夜间可读性。当前版本以内存 mock 数据为主，适合作为个人后台原型、权限控制台雏形或前后端分离练手项目。

## 项目特点

- **暗色控制台风格**：黑白灰、玻璃质感卡片、固定侧边栏与大标题层级。
- **前后端分离**：前端使用 Vue 3 + Vite，后端使用 Express 提供 API。
- **轻量好改**：没有复杂工程约束，页面、菜单和 mock 数据都可以直接调整。
- **基础后台模块完整**：登录、权限、字典、审计、任务、监控都有基础骨架。
- **真实表格体验**：模块页已从原始 JSON 展示升级为暗色数据表格，支持标签状态、列表字段和操作按钮。
- **高级筛选搜索**：模块页支持关键词搜索、状态/级别筛选、渠道筛选和筛选结果统计。
- **开发体验优化**：根目录提供统一脚本，附带环境变量示例和构建检查命令。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 登录鉴权 | JWT 登录、当前用户信息、菜单权限返回 |
| 星图总览 | 指标卡片、趋势柱图、最近审计动态 |
| 身份权限 | 用户、角色、菜单等基础权限数据 |
| 数据字典 | 账号状态、风险等级、来源渠道等配置 |
| 审计轨迹 | 操作记录、异常动作、来源渠道与级别 |
| 任务编排 | 任务名称、cron 表达式、运行状态、成功率 |
| 系统脉搏 | API 运行时间、资源占用、节点健康状态 |

### 前端

- Vue 3
- Vite

### 后端

- Node.js
- Express
- JWT
- dotenv
- 内存 mock 数据

## 快速启动

### 1. 安装所有依赖

```bash
npm run install:all
```

### 2. 启动后端

```bash
npm run dev:backend
```

后端默认地址：

```txt
http://localhost:4160
```

### 3. 启动前端

```bash
npm run dev:frontend
```

前端默认地址：

```txt
http://localhost:5173
```

默认登录：

```txt
admin / ashveil2026
```

## 环境变量

项目提供了示例环境变量文件：

```text
backend/.env.example
frontend/.env.example
```

本地开发时可以复制为 `.env` 后自行调整。

## 常用命令

```bash
# 安装前后端依赖
npm run install:all

# 启动后端
npm run dev:backend

# 启动前端
npm run dev:frontend

npm run build

```
