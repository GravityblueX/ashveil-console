# Ashveil Console

Ashveil Console 是一个我心血来潮做出来的暗色系管理控制台。最开始只是想把日常后台里常见的登录、权限、字典、日志、任务和监控功能揉到一个轻量项目里，顺手做成了前后端分离的结构，方便以后继续扩展。

整个界面走黑白灰和低饱和风格，不追求花哨，更偏向夜间值班、审计看板、内部运营台这一类使用场景。

## 我想做成什么样

- **轻量**：先把核心后台能力搭起来，不引入太重的工程体系。
- **好改**：前端页面、菜单、接口数据都尽量保持直观，方便二次调整。
- **暗色**：整体采用暗色玻璃质感，减少高亮色，让它看起来更像一个内部控制台。
- **模块清晰**：登录、权限、字典、审计、任务、监控拆开维护。

## 功能

- 登录鉴权：JWT 登录、当前用户、菜单权限
- 星图总览：指标卡片、趋势图、最近审计动态
- 身份权限：用户、角色、菜单等基础权限数据
- 数据字典：账号状态、风险等级、来源渠道等配置
- 审计轨迹：操作记录、异常动作、来源渠道
- 任务编排：任务定义、cron 表达式、运行状态
- 系统脉搏：服务运行状态、节点延迟、资源指标

## 技术栈

### 前端

- Vue 3
- Vite
- Pinia
- Vue Router
- 原生 CSS 暗色主题

### 后端

- Node.js
- Express
- JWT
- 内存 mock 数据

## 快速启动

```bash
# 启动后端
cd backend
npm install
npm run dev

# 启动前端
cd frontend
npm install
npm run dev
```

默认登录：

```txt
admin / ashveil2026
```
